# 推荐阅读规则

## 存放位置

推荐内容统一存放在 `_data/recommendations.yml`，由推荐阅读页面在构建时按加入时间倒序展示。

## 数据格式

每条推荐包含以下字段：

```yaml
- added_at: "2025-08-15"
  kind: article
  title: Control the ideas, not the code
  url: https://antirez.com/news/169
  note: 不要绝望，学习并适应。
```

### `added_at`

加入推荐列表的日期，格式为 `YYYY-MM-DD`。建议使用引号包裹，避免 YAML 将其解析为日期对象。

### `kind`

内容类型，只能使用以下值：

- `book` — 书籍
- `article` — 文章
- `video` — 视频

### `title`

推荐内容的原始标题。

### `url`

内容的直接访问链接。书籍优先使用出版社、作者主页或豆瓣链接。

### `note`

简短说明推荐理由或最有价值的地方。使用纯文本，通常控制在一两句话内。

## 添加规则

- 新增内容时自动记录当前加入日期，不使用内容本身的发布日期。
- 页面按 `added_at` 倒序展示；同一天的推荐按数据文件中的先后顺序展示。
- 添加前检查链接是否已经存在，避免重复推荐。
- 不添加封面、预览图和原始摘要；以后有明确需求时再扩展。
